# Employee Management System

## 1. Project Objective
The Employee Management System is a Python-based application that helps users manage employee information. It allows users to add, view, search, update, and delete employee records.

## 2. Features
- Add new employees with unique IDs.
- View all employee records.
- Search employees using their IDs.
- Update employee information.
- Delete employee records.
- Validate user input.
- Save employee data permanently using JSON.

## 3. Technologies Used
- Python
- JSON
- Visual Studio Code

## 4. Installation Steps
1. Install Python on your computer.
2. Download or clone the project.
3. Open the project folder in Visual Studio Code.
4. Ensure Python is installed and available in the terminal.

## 5. How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

   `python main.py`

4. Select an option from the menu and follow the instructions.
